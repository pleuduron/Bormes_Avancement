# Bormes — Tableau de bord d'avancement

Site statique de suivi d'avancement du projet Bormes-les-Mimosas.

## Publication
Le site est publié avec **GitHub Pages** depuis la branche `main` et le dossier `/(root)` à l'adresse :
https://pleuduron.github.io/Bormes_Avancement/

## Données
Le fichier `index.html` sera actualisé par un script exécuté localement dans QGIS.
Ne pas déposer de couches SIG, géométries, données individuelles, documents du client, fichiers Excel ou identifiants dans ce dépôt public.

La publication de données d'avancement professionnelles doit être autorisée avant le premier envoi.
